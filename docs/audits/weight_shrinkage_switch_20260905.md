# 가중치 축소 단위 전환(채점 건수 → 판단일)의 CHIEF 영향 기록 (2026-09-05)

`docs/gaeo_validation_policy.md` §14가 "적용 전후 같은 600종목 입력에서 CHIEF 판단이 몇 건 바뀌는지는
적용 PR 본문에 기록한다"고 했다. PR #506 본문에 적었지만 저장소 안에서 추적할 수 있도록 여기에도 남긴다
(건강검진 2026-09-05 분석 로직 점검 권고).

## 입력

- 판단 기록: `history.js`(2026-09-04 16:00 시점), 일봉: `analysis_data.json`(fetchedAt 2026-09-04 16:00)
- 자동판단 대상: `auto_analysis.js` 600종목(2026-09-04 16:13 생성분과 같은 입력)
- 비교: 건수 단위 `(hit + 60) / (n + 120)` vs 판단일 단위 `(적중률 × 판단일 + 10) / (판단일 + 20)`
- 재현: 별도 폴더에서 `compute_indicators.py → compute_team_weights.py → analyze_auto.py`를 두 산식으로 각각 실행

## 해석

- 변경은 모두 문턱(63/47)에 1점 걸친 경계 사례다. 산식의 방향은 보수적(사전비중 쪽)이다.
- BUY가 13% 줄어 사전등록 H1·H2 집단(각 30건·10판단일)이 조금 늦게 채워질 수 있다(치명적이지 않음).
- 이 전환은 DIANA 첫 채점(2026-09-14) 전에 정했고, 결과를 보고 고른 변경이 아니라는 독립 판정을 받았다
  (근거: 대상 사고의 자료가 없었음, 09-04 그림자로 공개된 식을 상수 변경 없이 켬, 방향 보수적,
  실제 효과는 "기준선 이하"로 판정된 QUANT의 발언권을 올리는 쪽). 다만 TARO·QUANT·FLOW에 대한 효과는
  결정 시점에 보이는 상태였으므로 "결과가 보이는 상태에서 고른 것"이 정확한 표현이다.
  앞으로는 "그림자 공개 → 한 검증 주기 뒤 적용"을 규칙으로 삼는다.
