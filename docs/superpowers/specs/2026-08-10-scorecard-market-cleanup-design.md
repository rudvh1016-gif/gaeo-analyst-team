# 성적표 통합과 시장 화면 정리 디자인

## 목적

메인 화면에서 부가 통계를 덜어내고, 처음 방문한 사용자도 의미를 바로 이해할 수 있는 메뉴 이름과 화면 구조를 제공한다. 실제 채점 표본이 있는데도 `표본 부족`으로 보이는 리더보드 오류를 함께 해결한다.

## 성적표와 리서치 통합

- 상단 주요 메뉴의 `리서치` 이름을 `성적표`로 변경한다.
- `성적표`를 누르면 기존 성적표와 애널리스트 리더보드 내용을 한 페이지에 세로로 표시한다.
- 전체 메뉴에 따로 있던 `리더보드`와 `성적표` 진입점은 하나의 `성적표` 진입점으로 합친다.
- 기존 `leaderboard` 주소와 링크는 없애지 않고 통합 성적표 화면으로 연결해 오래된 링크가 깨지지 않게 한다.

통합 성적표의 표시 순서는 다음과 같다.

1. 팀 전체 성적과 이번 주 결과
2. 분석가별 순위, 적중률, 채점 건수, 현재 발언권
3. 가장 잘 맞힌 판단과 가장 크게 빗나간 판단
4. 분석가별 강한 업종
5. 종합판단 v3 검증 현황

## `표본 부족` 오류 해결

- 실제 자동 집계 파일 `team_weights.js`에는 분석가별 총 21,099건과 팀 판단 8,319건의 채점 결과가 존재한다.
- 기존 리더보드는 지연 로드되는 `history.js`와 `price_history.js`를 다시 계산해 분석가 순위를 만들기 때문에, 화면이 해당 자료를 보지 못하면 실제 표본과 다르게 `표본 부족`을 표시한다.
- 통합 화면의 분석가별 누적 성적은 매 자동분석 주기에 미리 계산되는 `TEAM_WEIGHTS.global.acc`를 단일 표시 기준으로 사용한다.
- 각 분석가 카드에는 적중률과 함께 실제 채점 건수 `n`을 표시한다.
- 순위는 적중률을 우선하고, 적중률이 같으면 채점 건수가 많은 분석가를 우선한다.
- `TEAM_WEIGHTS`를 불러오지 못한 경우에만 오류 안내를 표시하며, 이를 `표본 부족`으로 오해하게 표현하지 않는다.
- 주간 성적과 개별 판단 사례는 날짜별 기록이 필요하므로 기존 `history.js`와 `price_history.js`를 계속 사용한다.

## 요일별 평균 등락률 이동

- 메인 화면에서는 `요일별 평균 등락률` 블록을 제거한다.
- 모바일과 PC의 햄버거 `전체 메뉴` 안에 `등락률 확인` 메뉴를 추가한다.
- `등락률 확인`을 누르면 전용 화면에서 기존 요일별 평균 등락률 통계를 표시한다.
- 전용 화면은 현재 요일별 통계만 포함한다. 이후 월별, 시간대별 등락률을 추가할 수 있도록 독립된 화면 컨테이너를 사용하되 이번 작업에서는 추가 통계를 만들지 않는다.
- 기존 `DOW_STATS` 계산과 설명, 표본 수, 색상 규칙은 변경하지 않는다.
- 홈이나 다른 메뉴를 누르면 등락률 전용 화면은 닫힌다.

## 코스피·코스닥 영역 정리

- `📈 코스피·코스닥 상세`를 `코스피·코스닥 상세`로 변경한다.
- `🇰🇷 코스피`를 `KR 코스피`로 변경한다.
- `📊 코스닥`을 `KR 코스닥`으로 변경한다.
- 이 영역의 장식용 이모티콘은 제거한다.
- 상승·하락 정보를 전달하는 색상과 `▲`, `▼` 기호는 유지한다.

## 반응형 화면과 접근성

- 통합 성적표는 모바일에서 카드가 한 열로 이어지고 가로 스크롤이 생기지 않게 한다.
- `등락률 확인` 메뉴는 모바일 전체 메뉴에서 다른 메뉴와 같은 크기의 터치 영역을 갖는다.
- 현재 열린 메뉴에는 기존 방식과 동일한 선택 상태를 표시한다.
- 통계 제목과 화면 컨테이너에 명확한 접근성 이름을 제공한다.

## 검증

- 자동 테스트로 상단 메뉴명이 `성적표`인지, 리더보드·성적표가 한 화면에서 렌더링되는지 확인한다.
- 분석가 카드가 `TEAM_WEIGHTS`의 적중률과 채점 건수를 사용하는지 검증한다.
- 실제 표본이 있을 때 `표본 부족` 문구가 나타나지 않는지 확인한다.
- 예전 `leaderboard` 링크가 통합 성적표 화면을 여는지 확인한다.
- 메인 화면에 요일별 통계가 없고, 전체 메뉴의 `등락률 확인`을 통해서만 열리는지 확인한다.
- PC와 모바일에서 통합 성적표, 전체 메뉴, 등락률 화면의 겹침과 가로 넘침을 확인한다.
- 코스피·코스닥 영역의 장식용 이모티콘이 제거되고 두 지수 모두 `KR` 접두어를 갖는지 확인한다.
- 기존 전체 테스트로 다른 메뉴와 시장 데이터 표시가 깨지지 않았는지 확인한다.
