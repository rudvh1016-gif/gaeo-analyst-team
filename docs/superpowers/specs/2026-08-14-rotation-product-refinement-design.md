# GAEO 순환매 최종 제품 개선 설계

## 목표

기존 순환매 엔진과 모든 검증·상세 콘텐츠를 보존하면서, 사용자가 5초 안에 `오늘 1거래일 변화`와 `추천 관찰기간의 중기 구조`를 구분하도록 순환매 화면을 재구성한다.

## 확인된 데이터 무결성

- 현재 스냅샷 생성시각은 `2026-08-13 15:23`, 데이터 마감은 `2026-08-13 15:23 장중`이다.
- 종목 가격 이력과 KOSPI·KOSDAQ 이력의 최신 거래일은 모두 `2026-08-13`이다.
- 추천 관찰기간은 Walk-forward 결과가 선택한 20거래일이며 UI에서 고정하지 않는다.
- 화장품·미용의 20거래일 점수 79.1은 같은 `2026-07-15~2026-08-13` 구간의 업종수익률 +11.1%, 시장 대비 +21.15%, 상승종목 비율 78.2%를 포함한 정상 계산이다.
- 같은 업종의 오늘 1거래일 값은 업종수익률 -1.24%, 시장 대비 -4.33%, 상승종목 비율 25.8%, 1일 점수 48.6이다. 따라서 “20거래일 1위이지만 오늘 약세”는 오류가 아니라 서로 다른 시간축이다.
- 워크플로는 가격 이력 → 지표 → 자동분석 → 순환 스냅샷 순으로 실행되며 현재 Scheduler 순서 오류는 확인되지 않았다.

## 설계 선택

### 채택: 기존 스냅샷의 기간별 데이터를 투영하는 UI 중심 개선

`recommendedHorizon`을 화면 전체의 단일 원천으로 유지한다. 추천 Horizon의 `periods[horizon]`은 중기 구조에, 동일 업종의 `periods[1]`은 TODAY에 사용한다. 새로운 예측 로직이나 LLM 호출은 추가하지 않는다.

이 방식은 계산 엔진을 바꾸지 않고 시간축을 정확히 분리한다. 스냅샷 스키마를 크게 늘리는 방식은 불필요한 생성·보관 위험이 있고, CSS만 바꾸는 방식은 오늘과 추천기간의 의미 혼동을 해결하지 못한다.

## 화면 구조

1. Hero는 `업종의 순환 흐름을 한눈에`로 수정하고 실제 자금 유입을 단정하는 표현을 제거한다.
2. 상단 요약은 현재 관찰, 추천 Horizon 1위, 오늘의 변화, 다음 후보, 시장 국면, 추천 관찰기간을 명확한 문장 위계로 보여준다.
3. 맵·순위·선택 업종 상세는 사용자가 별도 기간 버튼을 고르기 전까지 추천 Horizon을 함께 사용한다. 60·120·200일은 장기 추세 참고로 분리한다.
4. 순위 각 행은 추천 Horizon 점수와 오늘 1거래일 수익률·상태를 한 줄의 보조 정보로 함께 표시한다.
5. 선택 업종은 추천 Horizon 점수·순위와 TODAY 3개 지표를 분리하고, 두 시간축을 결합한 규칙 기반 자연어 해석을 제공한다.
6. 점수 방향은 확정 스냅샷 날짜, 전일/현재 점수, 실제 구성요소 기여 변화만 사용한다. 가짜 기여도는 만들지 않는다.
7. Lead-lag, 유사시장 성공·실패, 관련 종목, 현재 종합의견, 기간별 과거 성과, 중첩 평가, 지표 설명, 계산 방법은 모두 유지한다.

## 맵 레이아웃

현재 빈 공간은 오른쪽 순위+상세 열이 Grid 행 높이를 늘리지만 왼쪽 SVG가 `720×520`의 `height:auto`에 묶여 남는 높이를 쓰지 못해서 발생한다. Desktop에서 맵 패널과 SVG가 가용 높이를 사용하도록 하고, viewBox와 배치 좌표에 독립적인 `rx/ry` 타원 궤도를 사용한다. 노드 원 자체는 동일 반지름을 유지하므로 찌그러지지 않는다. Mobile은 기존 620×620 원형 배치를 유지한다.

## 시각 언어

- Pretendard 기반 기존 토큰을 유지한다.
- 흰 배경, 진한 잉크, 중립 회색을 중심으로 하고 파랑·빨강은 실제 데이터 의미에만 쓴다.
- 큰 내부 회색 카드, 반복 Pill, 반복 Progress bar, 과한 Shadow와 영어 Eyebrow를 줄인다.
- 내부 정보는 여백·얇은 Divider·글자 크기와 굵기로 구분한다.
- 모든 스타일은 `.rotation-view`/`.rot-*` 범위에 한정한다.

## 신선도와 오류 처리

- 생성시각, 순환 스냅샷 기준, 가격 기준을 중복 없이 표시한다.
- 스냅샷 날짜와 가격/계산기간 종료일이 다르면 경고 문구를 숨기지 않는다.
- TODAY 데이터가 없으면 숫자를 만들지 않고 `확인 중`으로 표시한다.

## 검증

- 엔진의 1/3/5/20 및 60/120/200, 추천기간, Walk-forward 결과가 변하지 않는지 비교한다.
- 추천 Horizon이 상단·맵·순위·선택 상세에서 일치하는지 테스트한다.
- TODAY가 1거래일 데이터만 사용하는지 테스트한다.
- 79.1 사례에서 “20거래일 중기 강세 + 오늘 약세”가 동시에 렌더링되는지 테스트한다.
- 1920/1440/1280/1024/768/390/360px에서 맵 크기, 노드 원형, 열 균형, 과도한 공백과 모바일 순서를 브라우저로 확인한다.
- 기존 보존 영역과 전체 저장소 테스트를 다시 실행한다.
