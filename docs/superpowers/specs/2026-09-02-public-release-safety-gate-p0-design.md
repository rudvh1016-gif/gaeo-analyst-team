# Public Release Safety Gate P0 설계

작성일: 2026-09-02
기준 커밋: `3704c7e1c77c893e049814f04183d0eab659f57b`

## 목표

공개 정적 페이지를 그대로 유지하면서, 브라우저가 저장소나 공개 게시판을 직접 수정하는 경로를 제거한다. 공개 문구는 실제 운영 방식과 일치시킨다. Growth Foundation P0의 URL, 색인, 콘텐츠, 제품 분석 계약과 기존 시장 데이터는 변경하지 않는다.

## 확인된 위험

1. 공개 페이지가 GitHub 개인 토큰을 `localStorage`에 저장하고 Contents API로 `main`에 직접 커밋한다.
2. 방문자 게시판의 비밀번호 검증이 브라우저에만 있어 KVdb 주소를 아는 사용자가 쓰기와 삭제를 우회할 수 있다.
3. 정적 화면의 관리자 비밀번호 해시는 인증 경계가 아닌데도 원격 권한처럼 보인다.
4. 익명 자체 집계가 제품 분석 동의와 별도로 증가한다.
5. 개인정보처리방침과 면책 문구가 실제 광고, 집계, 게시판 상태를 완전히 설명하지 않는다.

## 선택한 구조

### 소유자 발행

- 관리자 화면은 로컬 브라우저 초안 도구로만 동작한다.
- 토큰 입력, 토큰 저장, GitHub API 호출, 직접 `main` 커밋을 모두 제거한다.
- 발행 탭은 변경 파일 내용을 포함한 PR 작업 요청을 클립보드로 복사한다.
- 실제 발행은 별도 작업 환경에서 브랜치, 계약 테스트, PR, CI, 병합 순으로 수행한다.
- `#admin`과 다섯 번 탭은 숨겨진 로컬 도구 진입 동작일 뿐 인증이 아니라고 화면에 밝힌다.

### 커뮤니티

- `community.js`의 운영자 공지와 글은 계속 표시한다.
- 인증 없는 KVdb 방문자 글 읽기, 쓰기, 수정, 삭제를 공개 페이지에서 모두 제거한다.
- 방문자 영역은 읽기 전용 안내와 문의 링크를 표시한다.
- 현재 백업의 방문자 글이 0개이므로 이전할 사용자 글은 없다.

### 익명 집계와 제품 분석

- 기존 12개 제품 이벤트 분류와 속성 허용 목록은 바꾸지 않는다.
- 명시적인 분석 동의가 없으면 Google Analytics 이벤트와 자체 KVdb 집계를 전송하지 않는다.
- 공개 방문 숫자는 인증된 사용자 수가 아니라 조작 가능성이 있는 대략적인 카운터라고 표시한다.
- 광고 SDK의 존재와 제공자를 개인정보처리방침에 빠짐없이 공개한다.

### 공개 주장

- 서비스가 이용자에게 이용료, 회비, 구독료 같은 직접 대가를 받지 않는다는 현재 사실과 광고 수익 가능성을 함께 밝힌다.
- 개인별 자문, 1대1 유료 상담, 수익 보장 서비스가 아니라는 점을 분명히 한다.
- 과거 성과는 정해진 규칙으로 관측한 기록이며 인과적 우월성이나 미래 성과를 증명하지 않는다고 밝힌다.

## 검증

- 먼저 공개 산출물을 검사하는 실패 테스트를 추가한다.
- 테스트는 공개 HTML에 자격 증명 저장이나 GitHub API 쓰기 경로가 없고, 방문자 쓰기 폼과 KVdb 게시글 쓰기 경로가 없으며, 동의 전 집계가 차단되는지를 확인한다.
- 기존 Growth Foundation, 제품 분석, 성과 주장, 브랜드 계약을 모두 다시 실행한다.
- 작은 UI 변경은 로컬 브라우저에서 데스크톱과 모바일로 확인한다.

## 비범위

- GitHub 브랜치 보호나 ruleset의 자동 변경
- 전체 디자인 개편
- 분석 이벤트 taxonomy 변경
- 생성 데이터, 시세, 판단 기록 변경
- 법률 준수 완료 또는 검색/분석 성과 개선을 보장하는 주장
