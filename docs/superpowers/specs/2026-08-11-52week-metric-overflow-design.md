# 52주 지표 카드 숫자 넘침 수정 설계

## 문제

종목 상세의 `52주` 값은 `62,700 ~ 211,000`처럼 다른 재무지표보다 길다. 기본 레이아웃은 이 카드를 전체 폭으로 배치하지만, 화면 폭 1180px 이상에서는 `.qmetrics .qm-wide`를 일반 한 칸으로 되돌리고 최소 폭을 112px로 제한한다. 값은 `white-space: nowrap`이므로 일부 브라우저·글꼴 배율에서 숫자가 카드 오른쪽 경계를 넘는다.

실제 롯데쇼핑 화면의 1285px 뷰포트에서 카드 내부 값 영역은 92px인데 텍스트가 요구하는 폭은 102px였다. 현재는 오른쪽 패딩까지 침범하며, 렌더링 차이가 추가되면 경계 밖으로 넘는다.

## 승인된 해결 방식

- 1180px 이상 화면에서 `52주` 카드의 최소 폭만 112px에서 140px로 확대한다.
- 숫자의 현재 크기와 한 줄 표시는 유지한다.
- PER·PBR·ROE·EPS·배당수익률·시가총액 카드의 폭과 스타일은 변경하지 않는다.
- 1180px 미만에서 `52주` 카드가 전체 행을 사용하는 기존 동작은 유지한다.

## 검증

- 수정 전 실제 롯데쇼핑 화면에서 `.qm-val.scrollWidth > .qm-val.clientWidth`가 재현되어야 한다.
- 수정 후 1285px 데스크톱 화면에서 `scrollWidth <= clientWidth`여야 한다.
- 숫자 요소의 오른쪽 경계가 카드 내부 패딩 경계를 넘지 않아야 한다.
- 52주 값은 한 줄로 유지되어야 한다.
- 기존 JavaScript·Python 테스트가 모두 통과해야 한다.
