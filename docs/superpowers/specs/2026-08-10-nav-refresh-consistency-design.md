# 상단 새로고침 버튼 통일 디자인

## 목표

상단 새로고침 버튼의 크기와 시각적 무게를 검색, 프로필, 전체 메뉴 버튼과 통일한다.

## 디자인

- 새로고침 버튼은 기존 전용 빨간 원형 배경과 그림자를 사용하지 않는다.
- 검색·프로필 버튼과 같은 `global-icon-btn` 구조, 높이, 패딩, 글자 크기, 아이콘 크기, hover 처리를 공유한다.
- 버튼 순서와 문구는 유지한다: 검색, 새로고침, 프로필, 전체 메뉴.
- 좁은 화면에서는 다른 상단 아이콘 버튼과 동일하게 40×40px가 되고 글자 문구는 숨긴다.
- 클릭 시 새로고침, 처리 중 비활성화, 아이콘 회전, 접근성 설명, 상단 안내 줄은 그대로 유지한다.

## 검증

- 정적 회귀 테스트로 공용 버튼 클래스 사용과 전용 원형 장식 제거를 확인한다.
- 기존 내비게이션·요일별 통계·시장 요약·모바일 레이더 테스트를 함께 실행한다.
- 데스크톱 1680px, 초와이드 1920px, 모바일 390px와 다크 모드에서 실제 렌더링을 확인한다.
