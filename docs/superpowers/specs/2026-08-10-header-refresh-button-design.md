# 상단 새로고침 버튼 디자인

## 목적

정적 사이트 특성상 사용자가 열린 페이지를 계속 보고 있으면 새로 배포된 주가와 자동 분석을 놓칠 수 있다. PC와 모바일에서 항상 보이는 상단 메뉴에 명확한 새로고침 수단과 갱신 주기 안내를 제공한다.

## 배치와 표현

- PC와 모바일 모두 상단 메뉴의 검색 버튼 바로 오른쪽에 배치한다.
- 작은 `새로고침` 라벨을 원형 버튼 바로 위에 표시한다.
- 버튼은 모던한 빨간색 원과 흰색 회전 화살표 아이콘으로 구성한다.
- 기존 검색, 프로필, 전체 메뉴 버튼의 동작과 위치를 유지한다.
- 모바일에서는 64px 상단 메뉴 안에 들어가도록 라벨과 원형 버튼을 축소하되, 손가락으로 누를 수 있는 전체 터치 영역은 충분히 확보한다.
- 다크 모드에서도 빨간 원, 흰 아이콘, 작은 라벨이 선명하게 보이도록 한다.

## 안내 문구

상단 메뉴 바로 아래에 다음 문구를 작은 글씨로 항상 표시한다.

> 주가는 장중 약 10분마다, 자동 분석은 약 30분마다 갱신됩니다. 꼭 자주 새로고침을 진행해주세요!

- 안내 줄은 상단 메뉴와 함께 고정되어 화면을 내려도 계속 보인다.
- PC에서는 한 줄로 표시한다.
- 모바일에서는 읽기 쉬운 작은 글씨 두 줄로 표시한다.
- 안내 줄이 본문 첫 부분을 가리지 않도록 본문 시작 위치를 안내 줄 높이만큼 조정한다.
- 버튼의 제목과 접근성 설명에도 동일한 갱신 주기 정보를 제공한다.

## 동작

1. 사용자가 버튼을 누른다.
2. 버튼의 회전 화살표가 움직이고 버튼 상태가 `새로고침 중`으로 변경된다.
3. 중복 클릭을 막은 뒤 브라우저의 현재 페이지 전체를 다시 불러온다.
4. 새 페이지는 최신 정적 파일과 주가·자동 분석 자료를 다시 읽는다.

## 접근성과 오류 처리

- 버튼의 접근성 이름은 `최신 주가와 분석 새로고침`으로 지정한다.
- 항상 보이는 안내 문구를 버튼 설명으로 연결해 화면 읽기 기능에서도 갱신 주기를 알 수 있게 한다.
- 새로고침 호출 전에 버튼을 비활성화해 연속 클릭을 방지한다.
- 브라우저 기본 페이지 새로고침을 사용하므로 별도 네트워크 오류 화면은 추가하지 않는다.

## 검증

- 자동 테스트로 버튼 위치, 라벨, 안내 문구, 접근성 속성, 클릭 시 전체 페이지 새로고침 연결을 확인한다.
- PC와 모바일 크기에서 검색 버튼 바로 오른쪽에 표시되고 다른 상단 메뉴와 겹치지 않는지 브라우저로 확인한다.
- 고정 안내 줄이 PC에서는 한 줄, 모바일에서는 두 줄로 보이며 본문을 가리지 않는지 확인한다.
- 다크 모드와 키보드 초점 표시를 확인한다.
- 기존 전체 테스트를 실행해 검색, 프로필, 전체 메뉴 동작에 영향이 없는지 확인한다.
