# Final Product Maturity Program 설계

작성일: 2026-09-03
기준 커밋: `b00992485ac453a0af14120df8fb15e0c60754c0`

## 목표

Growth Foundation P0와 Public Release Safety Gate P0를 그대로 보존하면서 GAEO를 카드형 AI 대시보드에서 차분한 한국 주식 편집형 제품으로 정리한다. 사용자는 홈에 들어온 뒤 5초 안에 다섯 가지를 알아야 한다.

1. 코스피·코스닥 약 600종목을 다룬다.
2. 최근 거래일에 판단이 달라진 종목을 보여준다.
3. 내부 판단이 달라진 근거를 설명한다.
4. 모든 판단의 기준 시각과 데이터 상태를 확인할 수 있다.
5. 회사 이름이나 업종으로 즉시 검색할 수 있다.

## 선택한 방향

Variant B인 `GAEO Editorial Ledger`를 채택한다. 문서와 데이터가 먼저 보이고, 입력·버튼·차트·경고·광고·모달처럼 실제 경계가 필요한 요소에만 상자를 남긴다.

- 첫 화면의 유일한 강한 행동은 종목 검색이다.
- 큰 장식 카드 대신 제목, 설명, 행, 정렬된 숫자, 얇은 구분선을 사용한다.
- 근거와 기준 시각은 장식이 아닌 고정된 읽기 축으로 배치한다.
- 상승은 한국 시장 관례에 맞춰 빨강, 하락은 파랑을 유지한다.
- Wanted Sans Variable만 사용하고 본문은 400, UI는 500, 제목은 600, 브랜드와 대표 히어로만 800을 허용한다.
- 그라디언트, 글로우, 유리 효과, 분석가별 장식색은 사용하지 않는다.

## PR 1 구조

홈 히어로와 검색은 한 편집형 lead 영역으로 읽힌다. 브랜드, 명확한 한 줄 제목, 사실 범위, 신뢰 링크, 검색 순으로 배치한다. `heroLatestBtn`과 `heroChangesBtn`은 기능과 분석 계약을 보존하되 보조 text action으로 낮춘다.

Daily Brief, 시장 행, KPI, Radar, DART는 별개의 둥근 카드가 아니라 같은 문서의 연속 섹션으로 보인다. 검색 input/button, chart plot, stale/data warning, 광고, consent, modal, drawer는 기능 경계이므로 평탄화 대상에서 제외한다.

기존 ID와 JavaScript 연결은 모두 유지한다. 문구는 저장된 사실만 사용하고 `오늘`이나 `실시간`처럼 정적 페이지에서 틀릴 수 있는 시간 단정 대신 `최근 거래일`, `기준 시각`을 사용한다. 전체 600종목은 규칙 기반 자동분석이며 일부 지정 정밀분석만 AI 보조라는 경계를 흐리지 않는다.

## 후속 PR

- PR 2: 동일한 편집 문법을 나머지 화면으로 확장하고 WCAG 2.2 AA 접근성을 구현한다.
- PR 3: 실제 측정치를 기준으로 payload, loading, service worker, 유지보수성을 개선한다.
- PR 4: 방법론·역사적 판단·성과 문구·bias를 재검토하고 잔여 SEO·공유·획득·재방문·분석 운영을 강화한다.
- PR 5: workflow, main writer, compact history, data-live 준비도, ruleset 적용 안내와 stale branch 목록을 정리한다.

각 PR은 실제 최신 `origin/main`에서 독립 브랜치로 시작하고, 세 독립 검토와 전체 테스트, PR CI, 병합 후 프로덕션 검증을 거친다.

## 안전 경계

- 생성 데이터, 판단 모델, 가격·수급·분석 기록을 변경하지 않는다.
- canonical, robots, sitemap, 공유 URL, 동의, 공개 쓰기 차단 계약을 약화하지 않는다.
- 자동 종목 페이지는 crawl 허용 + `noindex,follow`를 유지하며 sitemap에는 넣지 않는다.
- 광고와 동의 UI를 일반 콘텐츠에 합치거나 숨기지 않는다.
- 수익·정확도·우월성·검증 완료를 단정하지 않는다.
- ruleset 활성 상태는 실제 설정 증거 없이 주장하지 않는다.

## 검증 전략

먼저 정적 계약과 렌더 계약을 실패시키고, 가장 작은 구현으로 통과시킨다. 대표 화면은 1440×1100, 1280×900, 768×1024, 430×932, 390×844, 360×800에서 밝은 화면과 어두운 화면을 확인한다. 검색, 관심종목, 메뉴, 모달, 동의, 분석 이동과 URL·색인 계약을 기존 브라우저 테스트로 재검증한다.
