# Public Release Safety Gate P0 구현 계획

> 기준: `origin/main`의 `3704c7e1c77c893e049814f04183d0eab659f57b`

**목표:** 공개 브라우저의 무인증 원격 쓰기와 자격 증명 보관을 제거하고, 실제 처리 방식과 공개 문구를 맞춘다.

**구조:** 정적 사이트는 유지한다. 원격 변경은 PR 경계 뒤로 옮기고, 공개 커뮤니티는 운영자가 Git으로 발행한 읽기 전용 콘텐츠만 제공한다. 제품 분석과 자체 집계는 같은 명시적 동의 상태를 공유한다.

---

### 1. 실패하는 공개 안전 계약 추가

- `test_public_release_safety_gate.py`에서 배포 산출물을 직접 검사한다.
- GitHub 토큰/API 쓰기, 공개 방문자 게시글 쓰기, 가짜 관리자 인증, 동의 없는 자체 집계를 각각 독립적인 실패로 만든다.
- 현재 `main` 기준으로 실패함을 확인한다.

### 2. 브라우저 원격 쓰기 제거

- `index.html`의 방문자 KVdb 게시판 읽기/쓰기/수정/삭제를 제거한다.
- 운영자 발행의 PAT 입력, 저장, Contents API 호출을 제거한다.
- 관리자 모드는 로컬 초안임을 표시하고 PR 요청 복사만 제공한다.
- 안전 계약을 다시 실행해 통과시킨다.

### 3. 동의 경계와 공개 숫자 정직성 보강

- 제품 분석을 기본 동의 필요 모드로 설정한다.
- 자체 KVdb 카운터 증가도 같은 동의 상태가 `granted`일 때만 허용한다.
- 작은 접근 가능한 동의 배너와 개인정보 설정 재열기 동작을 제공한다.
- 방문 숫자는 대략적이며 검증된 순사용자 수가 아님을 UI에 표시한다.

### 4. 공개 정책과 주장 정리

- `privacy.html`에 실제 저장 항목, Google Analytics, Google AdSense, Kakao AdFit, KVdb와 선택권을 반영한다.
- `disclaimer.html`에 직접 대가 없음, 광고 수익 가능성, 개인별 자문 아님, 과거 성과 한계를 반영한다.
- 비교 우월성을 단정하는 홈 성과 문구를 관측 사실 중심으로 낮춘다.

### 5. 운영·거버넌스 문서화

- `docs/BRANCH_GOVERNANCE_PLAN.md`에 현재 main 쓰기 주체, 권장 ruleset, 예외, 단계별 전환, 장애·롤백 절차, 수동 설정 절차를 기록한다.
- `docs/ARCHITECTURE.md`와 `docs/CURRENT_STATUS.md`의 폐기된 보안 설명을 현재 구조로 갱신한다.
- 저장소 설정은 변경하지 않는다.

### 6. 전체 검증과 전달

- 관련 Node/Python 계약, 전체 비브라우저 계약, Playwright 핵심 계약을 실행한다.
- Windows 고유 기준선 실패는 기존 알려진 5건과 비교해 새 회귀와 분리한다.
- 변경 파일과 생성 파일 churn을 검토한다.
- 커밋, push, PR, GitHub CI 통과, 병합 후 실제 `origin/main`을 확인한다.
