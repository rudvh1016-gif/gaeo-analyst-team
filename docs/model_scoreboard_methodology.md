# 모델 성적 대시보드 — 채점 방법 (2026-08-16)

성적표 화면의 「모델 검증」 구역이 어떻게 계산되는지 쉬운 말로 설명합니다.

## 모델 성적은 어떻게 채점하나요?

**그 당시 실제로 저장해 둔 판단만** 채점합니다.

- 기본모델: `history.js`에 매일 쌓이는 실제 판단 기록 (지우거나 고칠 수 없는 append-only)
- 연구모델 A/B/C: 판단 시점에 암호화 보관된 연구 기록(live shadow)

판단일로부터 **5·20·60 거래일**(주말·공휴일 제외) 뒤의 실제 종가로 채점합니다.
적중 기준은 기존 성적표와 완전히 같습니다: BUY는 +1% 초과면 적중,
SELL은 -1% 미만이면 적중, HOLD는 ±5% 안이면 적중.
결과가 아직 없으면 "기다리는 중"이지 0%가 아닙니다.

**미래 결과를 알고 나서 과거 판단을 다시 계산해 성적을 만드는 일은 하지 않습니다.**

## 왜 바로 순위를 안 매기나요?

- 판단일이 최소 20일 모이기 전에는 우연과 실력을 구분할 수 없습니다.
- 같은 날 600종목은 같은 시장 충격을 받아서 600번의 독립 시험이 아닙니다.
  그래서 "몇 건"과 "며칠"을 항상 같이 보여줍니다.
- 모델끼리 비교할 때는 **같은 날짜·같은 종목에서 둘 다 판단한 표본만** 씁니다.
  한쪽은 6,000건, 다른쪽은 200건인 상태로 %만 비교하지 않습니다.

## HOLD가 많으면 성적이 부풀지 않나요?

그래서 전체 적중률 하나만 보여주지 않고 **BUY / SELL / HOLD / 방향판단(BUY+SELL)**을
나눠서 보여줍니다. 시장이 통째로 오르내린 효과를 걷어낸 **시장 대비** 수치도
같이 봅니다(같은 날 분석 종목 전체 수익률 중앙값을 뺀 값).

## 500종목/600종목 기록을 왜 나누나요?

2026-08-15에 분석 대상이 500 → 600종목으로 늘었습니다. 새로 들어온 100종목은
그 전에는 판단 대상이 아니었으므로, 두 구간을 하나의 "현재 정확도"로 합치면
공정하지 않습니다. 또 2026-08-15에 기본모델 계산 방식이 개선돼(hotfix),
**개선 전 기록과 개선 후 기록도 섞지 않고 따로** 보여줍니다.
"현재 버전"의 성적은 개선 이후 기록이 쌓여야 나옵니다 — 그때까지는
"축적 중"이 정직한 표시입니다.

## 연구모델 A/B/C는 실제 서비스에 영향을 주나요?

아니요. 화면 판단은 언제나 기본모델입니다. A/B/C는 뒤에서 조용히 같은 데이터로
판단만 남기는 그림자 시험이고, **성적이 아무리 좋아도 자동으로 교체되지 않습니다.**
기준을 채우면 "검토할 만큼 기록이 쌓였습니다" 표시까지만 나오고,
실제 적용은 사람이 따로 승인해야 합니다.

- B는 후보 4개를 동시에 시험 중이고 **대표 후보를 고르지 않습니다.**
  결과를 보고 "이게 1등이니 대표"라고 고르는 순간 시험이 오염되기 때문입니다.
- 예측 확률(%)은 아직 실제 빈도와 맞는지 검증되지 않아(캘리브레이션 미검증)
  "실제 신뢰도"로 표시하지 않습니다.

## DART(공시)가 C에 도움이 됐는지는 어떻게 확인하나요?

C는 B와 **완전히 같은 조건에 공시 정보만 더한 짝**으로 설계돼 있습니다.
같은 종목·같은 날·같은 시간의 B 후보와 C 후보를 1:1로 비교해서
차이가 나는지만 봅니다. 지금은 공시가 방향 점수를 바꾸지 않는 단계라
둘의 판단이 같은 것이 정상이고, 그 자체가 대조군 역할입니다.
