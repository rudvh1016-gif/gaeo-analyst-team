## 이게 뭔가

한국 주식(코스피·코스닥) 600종목을 매일 분석해 BUY/HOLD/SELL로 보여주는 단일 페이지
웹사이트다. TARO 기술적분석 · DIANA 재무 · QUANT 확률통계 · FLOW 수급 · CHIEF 종합
캐릭터는 여러 AI가 토론하는 팀이 아니라 규칙 기반 계산 관점을 설명하는 역할 체계다.
600종목의 매일 자동분석에는 AI API를 쓰지 않으며, CHIEF 역할이 계산 결과를 종합한다.
실사용 주소는 `gaeoteam.com`(GitHub Pages, `main` 브랜치 기준)이다.

투자 리서치 콘텐츠 외에도 뉴스분석·종목공부·주식공부·부동산공부·계산기 등 금융 교육
콘텐츠를 함께 발행하는 콘텐츠 사이트이기도 하다.

## 왜 존재하나

- 개인 투자자가 종목마다 재무제표·차트·수급·뉴스를 일일이 찾아보지 않아도, 다섯 분석 관점을
  압축한 요약을 매일 무료로 볼 수 있게 하는 것이 목적이다.
- 초보 투자자도 이해할 수 있도록 쉬운 설명(용어 팝업, 초등학생 눈높이 문구)에 신경 쓴다.
- 투자 권유가 아닌 참고용 정보라는 점을 명확히 한다.

## 정직하게 알아야 할 핵심 — "정밀분석"과 "자동분석"의 차이

이 프로젝트에서 가장 오해하기 쉬운 부분이라 맨 위에 적는다.

- **🤖 자동분석 (600종목 전체, 매일)**: `analyze_auto.py`가 RSI·MACD·이동평균 같은 지표를
  계산해서, 미리 정해둔 규칙(if-then)으로 BUY/HOLD/SELL을 판단한다. **AI API를 전혀 호출하지
  않는 순수 파이썬 로직**이라 토큰 비용이 0원이다. 600종목 전부가 매일 자동으로 갱신된다.
- **🧠 정밀분석 (현재 14종목, 비정기)**: `analysis.js`에 있는 소수 핵심 종목만, Claude가
  직접 웹서치와 재무 데이터를 보고 사람처럼 분석해 쓴다. **자동으로 매일 갱신되지 않고,
  누군가(Claude)가 실제로 재분석 작업을 할 때만 갱신된다.** 화면에는 "정밀분석이 당일
  재분석됐고 시세도 실시간과 크게 다르지 않을 때만" 정밀분석을 우선 표시하고, 그렇지 않으면
  같은 종목이라도 자동분석을 보여준다.
- 마케팅 문구(제목·설명·about 페이지)에서 "정밀분석"이라는 단어는 쓰지 않는다 — 실제로는
  거의 하지 않는 작업이라, 이 단어를 넣으면 실제 서비스 내용을 과장하게 되기 때문이다
  (2026-07 초 실제로 이 문제로 문구를 여러 차례 수정한 이력이 있다).

## 이 프로젝트를 만드는 사람들 (에이전트 워크플로)

이 저장소는 **Claude Code와 Codex가 번갈아 작업**한다. 어느 쪽이 작업하든:

1. 먼저 [AGENTS.md](../AGENTS.md)를 읽는다 (공통 규칙, 충돌 시 우선).
2. 그다음 [CLAUDE.md](../CLAUDE.md)를 읽는다 (Claude Code 전용 보충 사항. Codex에게는
   참고용이지만 강제는 아니다).
3. 이 `docs/` 폴더의 나머지 3개 문서로 세부사항을 확인한다.

`README.md`는 2026-07-09 시점(500종목 체계 도입 이전, GitHub Pages 배포 이전)에 멈춰 있는
낡은 문서라 **참고하지 않는다.** 최신 정보는 이 `docs/` 폴더와 `AGENTS.md`/`CLAUDE.md`,
그리고 실제 코드가 기준이다.
