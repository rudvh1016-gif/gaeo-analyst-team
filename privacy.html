1. 기본 원칙과 직접 입력

Gaeo(이하 "사이트")는 회원가입과 로그인 기능이 없고, 이름·이메일·전화번호를 사이트 화면에서 직접 입력받지 않습니다. 공개 방문자 게시판은 안전한 서버 인증을 갖출 때까지 읽기 전용이며 방문자 글, 닉네임, 비밀번호를 받지 않습니다.

문의하기를 눌러 이메일을 보내면 입력한 주소와 본문은 이용자가 선택한 이메일 서비스와 운영자의 메일함에서 처리됩니다. 사이트 자체 서버에는 문의 내용을 저장하지 않습니다.

2. 브라우저에만 저장되는 항목

테마, PC 보기, 관심종목, 포트폴리오, 로컬 초안, 익명 통계 동의 선택은 현재 사용하는 브라우저의 저장소에만 남습니다. 사이트 운영자의 서버나 GitHub 저장소로 자동 전송하지 않습니다. 공용 기기에서는 사용 후 브라우저 데이터를 지워주세요.

3. 익명 이용 통계

첫 방문 시 익명 이용 통계를 허용할지 묻습니다. 선택 전과 거부 후에는 Google Analytics 제품 이벤트와 사이트 자체 카운터를 증가시키지 않습니다. 허용하면 페이지 종류, 콘텐츠 종류·번호, 6자리 종목코드, 허용된 캠페인 값, 버튼 이용 같은 제한된 신호만 보냅니다. 입력한 검색어, 이메일, 전화번호, 포트폴리오 금액은 제품 이벤트로 보내지 않습니다.

자체 방문 카운터는 KVdb에 숫자 합계만 저장합니다. 회원을 식별하는 정확한 방문자 수가 아니고 공개 저장소 특성상 조작될 수 있는 대략적인 참고값입니다. 네트워크 요청을 처리하는 제공자는 IP 주소, 요청 시각, 브라우저·운영체제, 요청 URI 같은 접속 기록을 처리할 수 있습니다.

4. 광고와 쿠키

사이트는 Google AdSense와 Kakao AdFit 광고 코드를 사용합니다. 광고 제공자는 광고 표시, 빈도 제한, 부정 이용 방지와 관련 광고 제공을 위해 쿠키, 기기·브라우저 정보, IP 주소, 광고 상호작용 정보를 각 제공자의 정책에 따라 처리할 수 있습니다. 익명 통계 선택은 사이트의 분석 신호를 제어하며 광고 제공자의 별도 설정을 대신하지 않습니다.

6. 보유 기간과 삭제

  • 브라우저 저장 항목은 이용자가 브라우저 데이터를 삭제할 때까지 남습니다.
  • Google Analytics와 광고 데이터는 각 제공자의 보유 설정과 정책에 따릅니다.
  • KVdb의 숫자 합계는 운영자가 집계 키를 삭제할 때까지 남을 수 있습니다.
  • 문의 이메일은 문의 처리와 분쟁 대응에 필요한 기간 뒤 운영자가 삭제합니다.
